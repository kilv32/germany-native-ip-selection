## 先分清：你要的「原生 IP」和「住宅 IP」不是一回事

原生 IP 说的是这个 IP 在本地注册、归属本地运营商，仅此而已。德国机房里一抓一大把原生 IP，它们全都不是住宅 IP。

真正的分水岭在 ASN。普通 VPS 的 IP 来自数据中心 ASN，OVH、Hetzner、Vultr 这类都属于 hosting 段。风控系统拿到这个 ASN 就直接打标签，后果是账号刚注册就限流、ChatGPT 报 Access denied、Netflix 提示用了代理、支付网关把交易标成可疑。住宅 IP 的 ASN 归属真实 ISP，在 ipinfo 里通常显示 `isp` 或 `residential`，Scamalytics、IPQS 这类库给出的 fraud score 也低。

这两件事在德国市场上被混得很厉害。同样标着「德国原生 IP」，有的商家卖的是双 ISP 住宅属性，有的只是机房原生段，价格能差一倍，用途也完全不同。

判定结果还会随数据库更新漂移，同一段 IP 在三个库里可能给出三种结论。下单前拿 ipinfo、Scamalytics、whoer 交叉查一遍，比看商家宣传语靠谱。真要严谨，直接开工单问 ASN 归属，商家答不上来或者绕圈子，这单就别下了。

还有一点容易被忽略：住宅 IP 只解决「IP 这一项不被扣分」。TikTok 的风控还看设备指纹、行为模式、内容质量、发布频率。指望换个 IP 就稳，是把问题想简单了。

## 9929、4837、IEPL 分别适合谁

这三个词在购买页上并排出现，很多人直接按价格选，结果买回去发现晚高峰卡成幻灯片。

**9929** 是联通 AS9929 精品网，走的是联通骨干里优先级最高的那一段。它的卖点从来不是「快」，是晚高峰不轻易掉速、丢包控制得住。商家宣传的「三网 9929」要理解成**回程**三网统一走 9929，去程电信可能走 CN2 或 163，联通走 AS9929 或 4837，移动走 CMIN2 或直连。下单后第一件事是用 `mtr` 看实际路由，跟宣传不符就在退款窗口内处理掉。

**4837** 是联通普通国际线路，口子给得大、价格便宜，代价是晚高峰波动明显。大流量下载、镜像同步、不要求稳定连接的场景用它划算。

**IEPL** 是专线，流量不走公网，稳定性最好，价格也最高。深港这条给 300Mbps / 500GB，明显是给企业中转和跨境办公准备的，个人用户买它属于杀鸡用牛刀。

德国这个位置有它自己的物理限制。法兰克福是欧洲最大的互联网交换节点之一，国际带宽充足，但从法兰克福到中国大陆的延迟正常就在 180ms 上下，比美西节点慢一截，比很多绕路的欧洲 BGP 直连（250ms 以上）要好。指望德国节点有香港的手感，方向就错了。

## 常见问题

**德国原生 IP 和德国住宅 IP 有什么区别？**
原生只说 IP 在德国本地注册、归属德国运营商；住宅说的是 ASN 属于真实家庭宽带运营商。机房里的原生 IP 一大把，能过 TikTok 和支付风控的住宅 IP 少得多。买之前查 ASN，别只看「原生」两个字。

**德国节点延迟多少算正常？**
法兰克福到中国大陆 180ms 上下是正常水平，200ms 出头也不奇怪，物理距离摆在那里。看到宣传「德国 120ms」的，多半是走了某种中转或者数据口径不一样。

**WePC 德国节点能解锁 ChatGPT 吗？**
德国不在 OpenAI 的封禁地区列表里，机房原生 IP 通常能正常访问。但解锁与否取决于 IP 段当前状态，没法当作合同条款。下单后先在退款窗口内测一遍。

**TikTok 用德国 IP 还会被限流吗？**
IP 属性只是一项。设备指纹、操作行为、内容、发布节奏同样参与判定。住宅 IP 的作用是让 IP 这一项不加分不减分。

**9929 是去程还是回程？**
通常指回程。去程各家走各自骨干，电信可能是 CN2 或 163，联通可能是 AS9929 或 4837，移动可能是 CMIN2 或直连。对去程有要求的，下单后用 `mtr` 实测。

**澳元计价怎么换算？**
